02 — Problem Definition

Owners approach renovation
with almost no leverage

GridOne targets the three structural frictions that break trust in the process — and dissolves each one with data.

01
Information asymmetry
Estimates arrive as a black box. Owners can't see how a number is built or whether it's fair, and cost overruns surface only after work begins.
Black boxNo transparent, measured basis for the price
02
Trust
Contractors go unverified. It's hard to know which professional or firm actually deserves the job — and the fallout is widespread.
32%of Ontario homeowners admit being scammed; only 15% think enough is done to prevent it
03
Regulatory complexity
The Ontario Building Code and Toronto by-laws are near-impossible to self-assess — covering structure, energy, plumbing, and fire safety.
4–12 wkstypical Toronto permit review; incomplete, non-compliant applications are the top cause of delay

05 — Prototyping · System Layers

Four layers, one continuous
data handoff

Each layer transforms the one below it and passes structured data up. Nothing is re-entered — the scan captured in Layer 1 is still doing work at the contract in Layer 4.

L1
Capture Layer
A 3D polygon scan is built from smartphone camera footage — real-world terrain and spatial data extracted as vertex geometry. This measured mesh is the single source of truth for everything downstream.
Smartphone capture3D polygon scanVertex geometry
→ passes up: measured spatial mesh
L2
Analysis Layer
Area, ceiling height, and openings are auto-extracted from the mesh. An Aging Index plus latent plumbing, electrical, and insulation risk are quantified into an instant, transparent estimate range — and a fit-scored consultant match.
Auto measurementAging IndexRisk quantificationFit score
→ passes up: measured scope + estimate range
L3
Verification Layer
On site, a 10-item Ontario Building Code & Toronto by-law checklist verifies compliance, while BLE-paired instruments stream live telemetry that AI reads and ranks into scored repair recommendations.
OBC · by-law checklistBLE telemetryLeica · Protimeter · FLIRAI scoring
→ passes up: verified, code-checked findings
L4
Contract Layer
Verified results are locked into a standard contract and closed with an e-signature, then matched to a Toronto-registered contractor to begin work — the whole chain traceable back to the original scan.
Standard contractE-signatureRegistered contractorsAudit trail
→ output: signed, auditable scope of work
05 — Prototyping · Service Components

Six steps, one pipeline

Capture → auto-analysis → transparent estimate → code check → measurement → contract, handled continuously inside one app. Each step inherits the data the previous one produced.

01
ScanInput — smartphone camera footage

A 3D polygon scan built from smartphone camera footage. Real-world terrain and spatial data are extracted as vertex geometry — the measured foundation everything downstream is built on.

3D polygon scanVertex geometrySmartphone capture
02
MatchInherits — scan mesh

Area, ceiling height, and openings are auto-extracted from the scan mesh, then a verified consultant is matched against the scope of work with a fit score.

Auto measurementFit scoreVerified consultants
03
EstimateInherits — measured scope

An Aging Index plus latent plumbing, electrical, and insulation risk are quantified to produce an instant, transparent estimate range — not a black box.

Aging IndexRisk quantificationInstant range
04
CodesInherits — estimate + site visit

On the consultant's site visit, a 10-item checklist grounded in the Ontario Building Code (OBC) and Toronto by-laws verifies compliance before anything is committed.

OBCToronto by-laws10-point checklist
05
InspectInherits — code-checked scope

Measurement instruments pair over BLE and stream live telemetry. AI reads the readings and recommends repairs by score, turning raw instrument data into a ranked action list.

Leica DISTOProtimeterFLIRBLE telemetryAI scoring
06
E-signInherits — verified inspection

Verified results are locked into a standard contract and closed with an e-signature — then connected to a Toronto-registered contractor to start the work.

Standard contractE-signatureRegistered contractors
