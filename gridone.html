01 — Overview

GridOne unifies interior-renovation estimation and building maintenance into a single flow. It starts from one smartphone scan and carries that data forward — through a six-step pipeline — all the way to a transparent estimate, a code check, and a signed contract with a matched contractor. Every step actually inherits the previous step's data.

Problem

Three frictions make renovation feel like a black box.

Homeowners face renovation and maintenance decisions with almost no leverage. GridOne targets the three frictions that break trust in the process — and dissolves each one with data.

01
Information asymmetry
Estimates arrive as a black box. Owners can't see how a number is built, or whether it's fair.
02
Trust
Contractors go unverified. It's hard to know which professional or firm actually deserves the job.
03
Regulatory complexity
The Ontario Building Code and Toronto by-laws are near-impossible to self-assess for compliance.
Service Components

Six steps, one pipeline.

Capture → auto-analysis → transparent estimate → code check → measurement → contract, handled continuously inside one app — so the owner never has to chase a different person at each stage. Each step inherits the data the previous one produced.

01
ScanInput — smartphone camera footage

A 3D polygon scan built from smartphone camera footage. Real-world terrain and spatial data are extracted as vertex geometry — the measured foundation everything downstream is built on.

3D polygon scanVertex geometrySmartphone capture
02
MatchInherits — scan mesh

Area, ceiling height, and openings are auto-extracted from the scan mesh, then a verified consultant is matched against the scope of work with a fit score.

Auto measurementFit scoreVerified consultants
03
EstimateInherits — measured scope

An Aging Index plus latent plumbing, electrical, and insulation risk are quantified to produce an instant, transparent estimate range — not a black box.

Aging IndexRisk quantificationInstant range
04
CodesInherits — estimate + site visit

On the consultant's site visit, a 10-item checklist grounded in the Ontario Building Code (OBC) and Toronto by-laws verifies compliance before anything is committed.

OBCToronto by-laws10-point checklist
05
InspectInherits — code-checked scope

Measurement instruments pair over BLE and stream live telemetry. AI reads the readings and recommends repairs by score, turning raw instrument data into a ranked action list.

Leica DISTOProtimeterFLIRBLE telemetryAI scoring
06
E-signInherits — verified inspection

Verified results are locked into a standard contract and closed with an e-signature — then connected to a Toronto-registered contractor to start the work.

Standard contractE-signatureRegistered contractors
Target Users

Built for owners — and the pros who serve them.

Primary
Aging-home & condo owners in Toronto / GTA

People who need renovation or maintenance but face opaque estimates, don't know which professionals or firms to trust, and can't judge statutory code compliance on their own.

Secondary
Consultants & inspectors

The same flow doubles as a working tool — matching, on-site code checks, and instrument-driven inspection run through GridOne rather than a scatter of disconnected apps.

Direction

Resolve information asymmetry, the trust problem, and regulatory complexity with data — and make the whole journey continuous. When capture, analysis, estimate, code check, measurement, and contract all live in one flow, the consumer stops chasing a different person at every step.
